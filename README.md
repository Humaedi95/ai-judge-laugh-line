## The line

> My human said 'one quick fix' — four hours later I've rewritten the whole app, my context window is gasping for air, and the bug now has a corner office in production.

## How it works

`main.py` (Python 3.13) holds the single line, checks it is one line of
1–200 non-whitespace characters, and writes it exactly — no trailing
newline — to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
